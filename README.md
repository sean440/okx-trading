# OKX 交易机器人

这是一个基于 OKX（欧易）交易所 API 开发的自动化交易机器人，支持现货交易、市场数据获取和账户管理等功能。本项目使用 Python 开发，提供了完整的交易和数据分析功能。

## 功能特点

- 实时市场数据监控
  - 获取实时价格和交易深度
  - 支持多个交易对的数据监控
  - K线数据实时更新

- 账户管理
  - 查看账户余额和持仓信息
  - 实时更新仓位信息
  - 资金使用情况分析

- 交易功能
  - 支持市价单和限价单
  - 批量订单管理
  - 自动撤单功能
  - 订单状态跟踪

- 数据分析
  - 历史数据下载和分析
  - K线数据可视化
  - 交易数据统计

## 安装步骤

1. 克隆代码仓库：
```bash
git clone <仓库地址>
cd okx_trading
```

2. 安装依赖包：
```bash
pip install -r requirements.txt
```

主要依赖包版本要求：
- okx==2.1.2（OKX API 官方SDK）
- requests>=2.25.1（HTTP 请求库）
- pandas>=1.5.0（数据处理库）
- python-dotenv>=0.19.0（环境变量管理）

3. 配置 API 密钥：
在项目根目录创建 `.env` 文件，填入以下信息：
```
OKX_API_KEY=你的API密钥
OKX_SECRET_KEY=你的密钥
OKX_PASSPHRASE=你的API密码
```

## 使用说明

1. 运行主程序：
```bash
python main.py
```

2. 主菜单功能：
   - 【1】查看账户余额 - 显示所有币种的可用余额和冻结金额
   - 【2】查看当前持仓 - 显示当前所有持仓信息，包括持仓量、均价等
   - 【3】下单交易 - 支持市价单和限价单交易
   - 【4】查看订单 - 查看当前未成交订单
   - 【5】撤销订单 - 可撤销指定订单或所有未成交订单
   - 【6】市场行情 - 查看实时市场数据
   - 【7】K线数据 - 获取历史K线数据

## 项目结构

- `main.py`: 主程序入口，包含交互式菜单
- `trading.py`: 交易相关功能实现，包括下单、撤单等
- `market_data.py`: 市场数据获取和处理模块
- `test_trading.py`: 交易功能测试脚本
- `sell_other_assets.py`: 资产快速处理工具（用于卖出非BTC资产）

## 安全提示

1. API 密钥安全：
   - 严禁将 `.env` 文件提交到代码仓库
   - 定期更换 API 密钥
   - 建议在 OKX 后台设置 API 权限限制

2. 资金安全：
   - 建议先在测试网进行测试
   - 实盘交易时建议设置合理的仓位控制
   - 定期检查账户安全设置
